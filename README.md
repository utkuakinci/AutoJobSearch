# AutoJobSearch

An automated job search tool designed to streamline, track, and optimize your job hunting process across various platforms.

## Status

🚧 **Early development.** The project is just getting started, and there is no runnable code yet. This README will grow as features land.

## Goals

- **Streamline:** Search for jobs across several platforms from one place.
- **Track:** Keep a single record of the jobs you've found and the applications you've sent.
- **Optimize:** Use what you've tracked to focus your search on the best opportunities.
